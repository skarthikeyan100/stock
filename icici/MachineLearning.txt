1. Understanding Machine Learning
Supervised Learning
  - Known input and output (Labeled data)
Unsupervised Learning
   - groups data only based on input data  (clustering)
Reinforcement Learning
  - Trial and Error learning
  - Learns through experience, no input data, dynamic

Linear Regression Problem
  predicts a number of continous value
Example: Predit house price

Classification problems
  - predict discrete responses like yes/no
  - data tagging, categorization
Example: CLassify flowers

Mathematics:
Linear algebra
Basic Equations
Probability

2. Framing Machine Learning Problems
works to 
a. Predict an outcome
b. Uncover trends and patterns
c. Have rules and steps that can't be coded
d. Dataset is too large to process by human

simple rules, predetermined steps - not for machine learning

Frame your problem
  - Define questions for model
  Define required inputs and expected outputs

AWS Linear Learner - Classification algorithm

XGBoost Algorithms - for numeric and continuous

Choose the algorithm
Check your Dataset

How each feature will predict the target

How will the model's ouput integrate with existing applications

Define success metrics
Long term cost and maintenance to run the model in production
