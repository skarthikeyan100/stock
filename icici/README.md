# ICICI Trading Platform

Node.js / TypeScript options trading platform for ICICI Direct (Prism), Alice Blue (ANT), Kite and Shoonya.

```bash
npm install
npx tsc
npm run processes   # orchestrator: data, trading and frontend processes
```

Rules and conventions: `CLAUDE.md`. Pending work: `ToDo.md`. All other documentation: `docs/README.md`.
